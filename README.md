# Kuyruklu Yıldız Randevu Sistemi (KYRS)

## Uluslararası Ciddiyet Beyannamesi

Bu yazılım, gezegenlerarası bürokrasinin en üst katmanında duran **Kuyruklu Yıldız Randevu Dairesi** tarafından onaylanmıştır.  
Halley, Hale-Bopp, NEOWISE ve ismi henüz kataloglanmamış utangaç kuyruklu yıldızlar ile **resmi görüşme** talep edebilirsiniz.

> Uyarı: Randevu onayı ortalama 76 yıl sürer. Acele edenler için "ekspres kuyruk" seçeneği yalnızca 19 yıldır.

## Neden Bu Proje Var?

Çünkü evren büyük, takvimler küçük.  
Çünkü bir kuyruklu yıldız size "müsait değilim" demeden önce evrak işlemek zorundadır.  
Çünkü bilim, şaka ve damga mühürü aynı cümlede durabilir.

## Kurulum

```bash
python3 randevu.py
```

Python 3 yeterlidir. Kuyruklu yıldız tarafında ek kütüphane gerekmez; onlar zaten gelir geçer.

## Kullanım

Program sizden:
1. Adınızı
2. Hangi gök cismini rahatsız etmek istediğinizi
3. Randevu sebebini ("sadece selam vermek" geçerli bir sebeptir)

sorar. Ardından **resmi tutanak** basar.

## Teknik Özellikler

- Rastgele ama bilimsel görünen bekleme süreleri
- Sahte protokol numaraları
- Yerçekimi ile uyumlu mizah
- Hiçbir API çağrısı yapmaz çünkü kuyruklu yıldızlar REST sevmez

## Sorumluluk Reddi

Bu yazılım gerçek bir kuyruklu yıldızı yörüngesinden sapamaz.  
Saparsa bu tamamen kuyruklu yıldızın kendi karıdır.
